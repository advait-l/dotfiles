# dotfiles

Personal dotfiles for zsh, tmux, Vim, and Neovim.

## Structure

```
dotfiles/
├── install.sh      # Symlink everything into ~
├── zsh/
│   └── .zshrc
├── tmux/
│   └── .tmux.conf
├── vim/
│   └── .vimrc
└── nvim/
    └── ...         # Full Neovim config
```

## Installation

```bash
git clone https://github.com/advait-l/dotfiles.git ~/dotfiles
cd ~/dotfiles
./install.sh
```

`install.sh` backs up any existing configs to `~/.dotfiles-backup/<timestamp>/` and then creates symlinks from the repo into your home directory.

## What's included

- **zsh** — `.zshrc` (Oh-My-Zsh + Powerlevel10k ready)
- **tmux** — `.tmux.conf`
- **Vim** — classic `.vimrc` using Vundle
- **Neovim** — config based on [kickstart.nvim](https://github.com/nvim-lua/kickstart.nvim) using lazy.nvim

## Not included (by design)

- `.gitconfig` — contains personal info; set it up manually or with `gh auth setup-git`
- `.p10k.zsh` — generated by `p10k configure`; run the wizard to create it
