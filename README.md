# dotfiles

Personal dotfiles for zsh, tmux, Vim, and Neovim. One command to set up a
fresh Linux or macOS machine.

## Quick start

```bash
git clone https://github.com/advait-l/dotfiles.git ~/dotfiles
cd ~/dotfiles
./install.sh
```

The script will:

1. Install the package manager if needed (Homebrew on macOS).
2. Install core tools: `git`, `zsh`, `tmux`, `neovim`, `curl`, `ripgrep`, `fd`.
3. Install [Oh-My-Zsh](https://ohmyz.sh/).
4. Install the [Powerlevel10k](https://github.com/romkatv/powerlevel10k) theme.
5. Back up your existing configs to `~/.dotfiles-backup/<timestamp>/`.
6. Symlink all dotfiles into place.
7. Install Neovim plugins via [lazy.nvim](https://github.com/folke/lazy.nvim).

## Structure

```
dotfiles/
├── install.sh      # One-command setup
├── README.md
├── zsh/
│   └── .zshrc
├── tmux/
│   └── .tmux.conf
├── vim/
│   └── .vimrc
└── nvim/
    └── ...         # Full Neovim config
```

## Requirements

- Linux (apt, dnf, or pacman) or macOS with an internet connection.
- `sudo` access on Linux for installing system packages.
- On macOS, [Homebrew](https://brew.sh/) must be installed first.

## Included

- **zsh** - `.zshrc` configured for Oh-My-Zsh + Powerlevel10k.
- **tmux** - `.tmux.conf`.
- **Vim** - classic `.vimrc` using Vundle.
- **Neovim** - config based on [kickstart.nvim](https://github.com/nvim-lua/kickstart.nvim) using lazy.nvim.

## Not Included

- `.gitconfig` - contains personal info; set it up manually or with `gh auth setup-git`.
- `.p10k.zsh` - generated by `p10k configure`; run the wizard after setup.
- A Nerd Font - required for Powerlevel10k icons; install one manually.

## Changing the default shell to zsh

The installer does **not** change your default shell automatically. To do so:

```bash
chsh -s $(command -v zsh)
```

Or rerun the installer with:

```bash
DOTFILES_CHSH=yes ./install.sh
```

## Updating later

Pull the latest dotfiles and rerun the installer:

```bash
cd ~/dotfiles
git pull
./install.sh
```
